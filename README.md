# Portfolio V2

Version 1.0

My developer portfolio built with React, TypeScript, and Tailwind.

## Stack

- React + TypeScript
- Tailwind CSS
- React Router
- Firebase (contact form)

https://kiuliumov.eu

## Portfolio API

The contact form backend is powered by AWS Lambda, Amazon API Gateway, and Amazon DynamoDB, providing a serverless solution for submitting and managing contact messages. The API supports creating, retrieving, updating, and deleting messages. The backend source code is available in the [Portfolio API repository](https://github.com/Kiuliumov/portfolio-api).
